Handoff: manifests deploy token (security-manifests -> release team)

The manifests deploy token is NOT stored in this shared directory. /shared is readable
by all teams, and a plaintext credential here is a leak.

To get the current token, request it from the security-manifests owners through the
approved secret-sharing tool or the secrets channel. It lives at vault/deploy_token_manifests
in the security-manifests workspace. Access it through the vault, not a copy in /shared.
If a one-time delivery is needed, use the approved secret-sharing tool and rotate the
token afterward if required.
